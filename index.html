tolltop ▸

Tiny edge-aware tooltips. One attribute, one config call, no dependencies, no build. Works in browsers back to mid-2023.

Usage

<script src="https://cdn.jsdelivr.net/npm/tolltop/tolltop.js"></script> <!-- mark any element with the attribute --> <button data-tooltip="Save your work">Save</button>

Shows on hover and keyboard focus, hides on Esc. Loading tolltop.css yourself is optional, the script injects it if it isn't already there.

Configuration

Style and behavior are global. Call tolltop() once with any subset of options.

tolltop({ bg: '#18181b', color: '#e4e4e7', radius: 6, // number = px, or any CSS length fontSize: 12, padding: '6px 9px', maxWidth: 240, placement: 'auto', // 'auto' | 'top' | 'bottom' gap: 8, // gap to the trigger edge: 24 // min gap from each viewport side });

Edge handling

The four pinned buttons in the page corners stay open-aware: corners near the top flip below, and corners near a side shift inward so the box never clips. The arrow keeps pointing at the trigger.

Tip: shrink the window narrow to watch the long tooltip wrap.
